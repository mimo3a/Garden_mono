# Frontend — React 18 + Vite

Порядок выполнения задаётся вехами в `docs/ROADMAP.md`. Правила — `docs/AGENT.md`.
Код: `garden-frontend/`. Сборка: `npm ci && npm run build`. Спецификация интерфейса — `garden-frontend/FRONTEND_SPEC.md`.

## Исходное состояние (на 2026-10-25)
- Данные: `GET /api/sensors/{id}/history` — вся история; агрегация и фильтр по диапазону на клиенте (`src/utils/sensorData.js`).
- Каналы `soil1`–`soil4` зашиты в `SensorCard.jsx` и `SensorDetail.jsx` — каналы 5–8 L476 не будут показаны.
- Окно «online» = 30 мин (`ONLINE_WINDOW_MS` в `sensorData.js` и **отдельная копия** функции `isOnline` в `SensorList.jsx`), а интервал измерений — 60 мин.
- Пороги статуса — `src/constants/thresholds.js`. Тексты интерфейса — на английском.
- Нет линтера и тестов.
